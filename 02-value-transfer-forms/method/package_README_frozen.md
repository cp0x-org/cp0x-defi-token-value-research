# Этап 3. Форма передачи стоимости и цена governance-токена: пакет материалов

Итоговый отчёт: STAGE3_SUMMARY.md. Всё остальное нужно, чтобы проверить и воспроизвести его числа и выводы.

## Состав

Отчёт и журнал
- STAGE3_SUMMARY.md: итоговый отчёт.
- STAGE3.md: рабочий журнал этапа с обоснованием каждой даты и классификации. Разделы с недействительными числами помечены баннером; действующие результаты в разделах 43 и 44.

Расчёт исходов
- stage3_outcomes.py: движок. Календарные окна, подбор двойников, сравнение с корзиной, проверка устойчивости знака.
- config.json, events.csv, data/prices.csv: входные данные движка.
- data/stage3_outcomes_recomputed.csv: результат движка, источник всех чисел таблицы результатов отчёта.

Классификация событий
- data/stage3_registry.csv: реестр переходов. Формы до и после, даты решения и фактического запуска, слой контроля, сила сопутствующих событий, причины исключения.
- data/stage3_events_v19_input.csv: исходный файл событий, с проверки которого начинался этап.

Систематический поиск переходов
- data/holders_rev_raw.json: сырая выгрузка DefiLlama, источник перечня протоколов.
- build_universe.py: восстанавливает перечень из выгрузки и сверяет его с замороженным.
- data/stage3_universe_frozen.csv и .sha256: замороженный перечень 164 протоколов с контрольной суммой.
- C_PROCEDURE_FROZEN.md: замороженная процедура поиска и её калибровка.
- c_screening.py: автоматический скрининг. data/screen_cache: сохранённые ответы всех источников, позволяют повторить скрининг без сети.
- data/stage3_c_auto_screening.csv и _evidence.csv: результаты скрининга и все собранные свидетельства, с ручной QA-разметкой.
- data/stage3_c_manual_queue.csv: вердикты ручной проверки очереди.
- data/stage3_search_log.csv: журнал всех поисковых шаблонов и калибровок, включая отрицательные результаты.

## Как воспроизвести

    python3 stage3_outcomes.py      # пересоздаёт data/stage3_outcomes_recomputed.csv
    python3 build_universe.py       # сверяет перечень протоколов
    cd data && sha256sum -c stage3_universe_frozen.sha256
    DA_DIR=<путь к клону DefiLlama/dimension-adapters, коммит 1029ba611a85d425d3a022d5f274fd3b9c6a29a0> \
      python3 c_screening.py --start 0 --end 164 --out data/rerun.csv

## Результат проверки пакета

Пакет проверен запуском в чистой папке, только из перечисленных файлов. Результат движка исходов совпал с действующим байт в байт. Перечень восстановлен точно, 164 протокола, контрольная сумма сходится. Повторный скрининг всех 164 протоколов из кеша не дал ни одного расхождения в статусах, фрагментах, источниках и числе свидетельств.

## Статус и открытые вопросы

Этап 3 закрыт. Исходы прошли три раунда внешней проверки воспроизведения. Kyber исключён из сравнения из-за разрыва между сменой формы выплат и полноценным потоком. Vertex не включён, потому что точная дата первого потока не установлена. Impermax показан как гибридный случай вне перечня.

Вне этого пакета остаются плацебо-тест этапа 2, который нужно пересчитать с календарными окнами, и независимое воспроизведение ключевых чисел этапов 1–2 перед объединением.
