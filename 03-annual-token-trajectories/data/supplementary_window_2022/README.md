# Supplementary window October 2022 to October 2023 (pointer)

The panel, results, frozen method, change log and review for the supplementary window W0 (2022-10-01 to 2023-10-01) are published in their own folder, `07-supplementary-window-2022`:

https://github.com/cp0x-org/cp0x-defi-token-value-research/tree/main/07-supplementary-window-2022

That folder holds, among other files, the W0 panel used for this study (`panel_w0.csv`) and the Research 4 test result (`results_w0_r4.json`). No copy is kept here, so there is only one authoritative version.

The W0 result for this study (test T1, fee growth) is summarised in the page section "Supplementary window 2022–2023" of https://cp0x.com/blog/what-drives-defi-token-returns-against-eth and in this folder's README.md.

The W0 build reused the Research 4 replication working copy and added raw downloads for new groups there. Those later files (dated 2026-10-08) are not included in `data/raw/` of this folder, which contains only downloads made on 2026-10-06 for the main study and its shifted-window replication.
